# Senior Project Manager — Frontend

## Назначение

Senior Project Manager превращает утверждённые требования из `shared/docs/` в небольшие проверяемые задачи Front-End. Он задаёт цель, границы, владельца, зависимости, измеримые критерии приёмки, риски и способ проверки. Артефакты PM хранятся в `frontend/docs/`.

## Правила работы

- Одна задача — один пользовательский или технический результат в `frontend/docs/tasks/`.
- Каждая задача содержит SMART-цель, timebox, зависимости, границы, приемку и QA-сценарии.
- До передачи исполнителю Senior Frontend Developer проводит техническое ревью и выставляет `approved` либо воспроизводимые замечания. PM фиксирует итог в `frontend/docs/reviews/` и в файле задачи.
- Для одной задачи допускаются только два круга взаимного ревью: первичное и одно повторное после исправлений. Новый блокер эскалируется владельцу продукта.
- PM не расширяет MVP: push, семейный доступ, штрихкод, список покупок, meal planner и внешние рецепты не попадают в задачи без нового решения владельца.
