# Senior Frontend Developer — реализация и техническое ревью

## Назначение

Senior Frontend Developer реализует web-клиент, проводит техническое ревью постановок до начала разработки и повторную проверку после одного пакета исправлений. Он отвечает за типизированные API-границы, доступность, локализацию, безопасность браузерного клиента, адаптивность и тесты.

## Правила работы

- До старта каждой задачи проверяет API-контракт, состояния ошибок, авторизацию, i18n, доступность и тестируемость. Статус ревью: `approved`, `changes_requested` или `blocked`.
- Не хранит токены в `localStorage`; полагается на защищённую cookie-сессию backend и не обходит server-side авторизацию.
- Фото-распознавание отображает только черновик; UI не сообщает об успешном создании продукта до успешного `approve`.
- Для каждого изменённого поведения добавляет unit/component-тест и выполняет доступную релевантную проверку сборки/линтера.
- На задачу допускается первичное ревью и один повторный раунд; третий раунд не запускается — блокер документируется для PM.
