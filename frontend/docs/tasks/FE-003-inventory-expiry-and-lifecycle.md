## SMART-цель

За четыре рабочих дня реализовать экран «Мои продукты», который получает только продукты текущего пользователя, сортирует/фильтрует их по согласованному API и позволяет отметить продукт использованным или выброшенным. Пользователь различает активный, attention, expired, used и discarded статусы без опоры только на цвет.

## Границы

- Подключить подтверждённые backend endpoints списка, детализации и lifecycle из BE-004; использовать server-side статус/recipe eligibility из BE-005. До отдельного согласования query-параметров BE-004 получать полный список и выполнять сортировку/фильтрацию на клиенте.
- Показывать локацию, группу, тип даты, абсолютную и относительную дату, текстовый статус и доступные действия.
- Не вычислять юридический момент истечения и не добавлять покупки/семейный доступ.

## Приёмка

- [ ] Пустой список объясняет действие и содержит CTA «Добавить продукт».
- [ ] Сначала показаны ближайшие значимые даты; доступны фильтры локации, группы и статуса.
- [ ] `use by` после срока — «Просрочен», без CTA рецепта; `best before` после даты — «Требует внимания» с предупреждением.
- [ ] Для страны со статусом `research_required` UI показывает «Правило уточняется» и не заменяет это состояние своим сроковым статусом или обещанием e-mail-напоминания.
- [ ] «Использован» и «Выброшен» требуют понятного подтверждения и после успеха обновляют UI без дублей.
