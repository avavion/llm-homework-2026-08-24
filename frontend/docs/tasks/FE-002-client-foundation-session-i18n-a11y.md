# FE-002 — Каркас клиента: сессия, i18n и доступность

- **Исполнитель:** Senior Frontend Developer
- **Статус:** blocked: эскалация PM по country/profile API
- **Зависимости:** FE-001, BE-003, согласованный country/profile API
- **Timebox:** 3 рабочих дня
- **Technical review:** approved, круг 1/2; [запись](../reviews/2026-08-26-frontend-technical-review.md)

## SMART-цель

За три рабочих дня создать запускаемый web-клиент с публичными и защищёнными маршрутами, регистрацией с выбором страны, входом/выходом через cookie-сессию BE-003, переключением ru/en и доступным базовым layout. Неавторизованный пользователь при открытии защищённого маршрута получает предсказуемое перенаправление на вход.

## Границы

- Подключить только контракты `POST /v1/auth/register`, `POST /v1/auth/login`, `POST /v1/auth/logout`, `GET /v1/auth/session` после их подтверждения backend.
- Выбор страны реализуется только после согласования передачи/хранения `country_code`, группы регулятора и account-scoped profile endpoint; текущий BE-003 этого контракта не публикует.
- Токены не сохранять в `localStorage` или URL; UI не содержит пароль в логах и сообщениях об ошибках.

## Приёмка

- [ ] Успешный login открывает защищённый shell; logout возвращает на страницу входа.
- [ ] Неверные учётные данные и ошибка сети показаны пользователю без раскрытия чувствительных деталей.
- [ ] Все базовые строки есть на ru/en; переключение сохраняет текущий маршрут.
- [ ] Страна передаётся в согласованном DTO регистрации; приложение не подменяет её группой регулятора и не делает вывод о сроках на этапе регистрации.
- [ ] Формы полностью управляются клавиатурой, имеют label, focus и связанное текстовое сообщение об ошибке.

## QA

Unit/component-тесты форм и route guard. Playwright: login/logout, ошибка login, навигация Tab и viewport 320/768/1440.

## Эскалация

Требуется решение Senior Project Manager и backend-владельца: расширить BE-003 или создать новую backend-задачу с DTO регистрации/профиля, полями страны и группы регулятора, authorization и ошибками. До решения разрешена только изолированная работа с тестовыми fixtures; production-интеграция заблокирована.
