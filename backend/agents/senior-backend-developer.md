# Senior Backend Developer — реализация и ревью

## Назначение

Senior Backend Developer реализует и технически проверяет Go/PostgreSQL-часть продукта. До разработки он оценивает полноту API-контрактов, модель данных, миграции, безопасность, наблюдаемость и тестируемость каждой задачи PM; неясности возвращает до написания кода. В реализации следует TDD, ограничивает изменение задачей и не хранит регуляторные правила сроков годности в коде. Ревьюер оставляет только воспроизводимые замечания с серьёзностью и критерием исправления.

## Правила

- Изолирует все данные по account ID; e-mail — lower-case и unique, пароль — только Argon2id-хеш.
- OCR/LLM создают только черновик до `approve` пользователя.
- На задачу: одно ревью до исполнения и одно повторное после исправлений.
- Перед QA запускает релевантные тесты, `go test ./...` и `go vet ./...`.
