## Размышления

Корень logout-дефекта — порядок побочных действий: ранний возврат по ошибке БД
происходил до формирования expired cookie. Минимальная правка меняет только
порядок, сохраняя `500` для неуспешной server-side invalidation.

Для integration strategy выбран Dockerfile build stage, поскольку runtime image
намеренно не содержит Go toolchain. Tagged test выполняется внутри Compose
database network и проверяет реальный pgx repository; PostgreSQL не получает
host port. Make target использует отдельное имя проекта, фиксированные безопасные
локальные credentials и trap cleanup, поэтому не затрагивает dev volume и не
может унаследовать внешний `DATABASE_URL`. SQL mocks/SQLite отвергнуты из-за
несовпадения PostgreSQL unique/concurrency semantics.

Самокритика: Docker image остаётся в локальном cache, но контейнеры, network и
данные удаляются; cache не является test evidence/state и ускоряет повторный
запуск. Статус technical review не повышен до approved без независимого
подтверждения. Product authorization и frontend не изменялись.
