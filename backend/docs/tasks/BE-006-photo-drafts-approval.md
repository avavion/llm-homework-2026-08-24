# BE-006 — OCR/LLM-черновики с approve/reject

**Исполнитель:** Senior Backend Developer · **Статус:** draft · **Зависимости:** BE-003, BE-004 · **Timebox:** 4 дня

## SMART-цель

Реализовать распознавание фото, которое создаёт только черновик, а продукт появляется исключительно после `approve` владельца.

## Объём и приёмка

- OCR/LLM интерфейсы, product_drafts, recognize/approve/reject API и fallback на ручную форму.
- После recognize в products нет записи; approve создаёт один продукт с отредактированными данными.
- Reject не создаёт продукт; другой account ID не может управлять черновиком.
- Ошибка адаптера не раскрывает секреты и не блокирует ручной ввод.

## Контроль

**Ревью Developer:** изоляция drafts, адаптеры, валидация approve.  
**QA:** пустое фото, плохой OCR/LLM, timeout, чужой ID, reject и двойной approve.
