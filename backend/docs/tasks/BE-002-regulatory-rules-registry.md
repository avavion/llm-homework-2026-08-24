# BE-002 — Реестр регуляторных правил и групп продуктов

**Исполнитель:** Senior Project Manager + исследователь · **Статус:** draft · **Зависимости:** нет · **Timebox:** 3 дня

**План:** [2026-08-26-be-002-regulatory-rules-registry.md](../superpowers/plans/2026-08-26-be-002-regulatory-rules-registry.md)

## SMART-цель

Опубликовать проверяемый реестр стран СНГ/ЕС, групп регуляторов, типов дат и групп продуктов, который включает автоматизацию только при наличии первичного источника.

## Объём и приёмка

- Создать `shared/docs/regulatory-date-rules.md` и `shared/docs/product-group-alert-policy.md`.
- Каждая включённая строка содержит ISO страны, источник, дату доступа, тип даты, момент истечения и статус/допуск рецептов.
- Непроверенные правила имеют `research_required`; ЕАЭС не получает выдуманное правило 00:00.
- Пять начальных групп имеют обоснованный порог; пользовательский минимум — 60 минут.

## Контроль

**Ревью Developer:** реестр преобразуем в конфигурацию без неясных значений.  
**QA:** URL, даты доступа и отсутствие автоматизации для `research_required`.
