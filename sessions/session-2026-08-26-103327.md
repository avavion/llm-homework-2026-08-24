## Размышления

Исходный шаблон был полезен для технической аудиторской сводки, но не позволял
следующему участнику восстановить диалог и причину решений. Новый формат делает
журнал самодостаточным: видимые метаданные и итог написаны для человека, а
служебные идентификаторы сохранены в HTML-комментариях для hook. Сам hook не
видит сообщения модели, поэтому фиксировать реплики обязан агент; это явно
указано в правилах, чтобы не создавать ложного ожидания автоматической записи.

Полный набор проверок также обнаружил гонку, существовавшую до смены шаблона:
при одинаковом времени несколько процессов могли выбрать одно имя перед
записью. Причина — разрыв между проверкой существования файла и записью.
Создание заменено на атомарное exclusive create с последовательным подбором
суффикса при конфликте.
