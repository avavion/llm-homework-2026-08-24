## Размышления

- Корневая команда должна запускать API рядом с PostgreSQL в Docker-сети: локальный macOS-бинарник не может надёжно подключаться к внутренней Docker-сети без публикации базы наружу.
- `bin/api` создаётся при `make build` для текущей платформы. При `make up` API запускается как Linux Go binary `/api` из существующего Docker-образа, что сохраняет приватность PostgreSQL.
- Ошибка Vite была вызвана неполным `frontend/node_modules`: `react-hook-form` есть в lockfile, но отсутствовал на диске. Чистый `npm ci` воспроизводимо восстанавливает все зависимости.
- В среде агентского runner дочерние процессы скрипта завершаются после завершения команды; для фактической проверки production frontend Vite preview был запущен напрямую. На локальной машине `make up` оставляет фоновый preview работающим штатно.
